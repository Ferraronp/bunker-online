# ADR-0002: Снимок игрового пака в комнате

**Статус:** реализовано в исходной версии. **Дата фиксации:** 2026-11-10.

## Контекст
Игровые паки редактируются администратором, но текущая партия не должна менять свои параметры из-за последующего редактирования каталога.

## Решение
При создании `Room` копируется `Pack.content` в `Room.pack_snapshot` (JSON); старт и логика партии используют сохранённый снимок.

## Последствия
+ Предсказуемые правила уже созданных комнат.
+ Кастомизация пака не меняет незавершённые партии.
− Дублирование конфигурации увеличивает объём хранения.
