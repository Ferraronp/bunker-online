### Проблема
Исходный архив v0.6 содержит диапазоны Python/npm-зависимостей; `frontend/package-lock.json` отсутствует. В чистой среде версии могут различаться.

### Воспроизведение
Посмотреть `backend/requirements.txt` и `frontend/package.json`, выполнить `npm ci` в чистом клоне (без lock-файла команда невозможна).

### Критерий устранения
Зафиксированы зависимости под Python 3.12 и Node 22, `npm ci` и Docker build проходят в CI; версии зафиксированы/обновляются контролируемо.
