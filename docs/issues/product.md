## Обсуждение и согласование продукта с преподавателем

**Название:** Последний рубеж — многопользовательский веб-Бункер.  
**Происхождение:** собственный проект (игровой MVP 0.6.0), учебная документация по существующему коду.  
**Роли:** ведущий, игрок, зритель, администратор контента.  
**Сущности:** Pack, Room, Player и логические Card, Vote.  
**Главные функции:** создать комнату/войти; раздать и раскрыть карты; провести голосование и завершить партию.  
**Стек:** React + TypeScript + FastAPI + PostgreSQL + WebSocket + Docker Compose.  
**Документы:** `docs/00-project.md`, `docs/01-requirements.md`.  
**План:** требования и UML (лаб. 2), архитектура (3), реализация инкремента (4), тестирование (5), выпуск (6), см. паспорт, раздел 12.

**Нужно от преподавателя:** подтвердить выбор проекта, допустимость учебной копии исходного архива и план. **Закрыть только после согласования.**
