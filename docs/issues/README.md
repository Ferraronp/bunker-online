# Подготовленные GitHub issues для лабораторной №1

Файлы ниже — **черновики** для публикации в новом репозитории; они не заменяют настоящие GitHub issues.

1. `product.md` — согласование проекта с преподавателем, держать открытым до его одобрения.
2. `dependency-lock.md` — проблема воспроизводимости зависимостей (`bug`).
3. `monoliths.md` — необходимость декомпозиции (`question`).
4. `frontend-e2e.md` — необходимость браузерного тестирования (`question`).

Issues создаются в GitHub на основе файлов из этой папки. Перед публикацией необходимо сверить текст с текущим состоянием проекта и назначить реального ревьюера.
