# Модели системы — лабораторная №2

Семь диаграмм, каждая в двух основных форматах: `*.puml` (исходник PlantUML) и `*.png` (экспорт). Дополнительные `*.dot` — Graphviz-версии, использованные для получения PNG без внешних сервисов. Все модели фиксируют **текущую реализацию MVP 0.6**, а не гипотетический SaaS.

PNG можно пересоздать командой `dot -Tpng docs/diagrams/context.dot -o docs/diagrams/context.png` (и аналогично для остальных); для визуального экспорта непосредственно из PlantUML используйте свой PlantUML CLI. Раздел 4 спецификации содержит ссылки и FR/US-трассировку.
